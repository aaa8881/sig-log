# 시그로그

시그의 작업 기록과 목표, 생각을 모아 두는 사이트.

- **기록:** Claude, Codex, Antigravity에서 한 작업을 AI가 매일 정리해서 올린다.
- **내일 할 일:** 가장 최근 기록에서 남은 일만 보여 준다.
- **목표:** 주간·월간 목표는 [goals.md](goals.md)에 직접 적는다.
- **생각:** `thoughts/` 폴더에 직접 적는다. 사이트의 "생각 적기" 버튼을 누르면 GitHub에서 바로 새 글을 쓸 수 있다.

`main`에 변경이 올라가면 GitHub Actions가 빌드해서 GitHub Pages로 배포한다. 기록 형식과 갱신 절차는 [AGENTS.md](AGENTS.md)에 있다.
