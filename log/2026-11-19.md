# 2026-11-19

## 베어타운

- 보스 상자 모델 재작업
  - 네모난 AI 티가 나던 상자 모델을 참고 에셋과 비교해 다시 만들고, 보스별로 같은 상자를 쓰도록 정리(P0~P3)
  - 자물쇠 문양, 열린 상자 안쪽과 위아래 디테일을 보강하고, 잘 나온 방식을 모델 검수 절차로 정리
- 주간 보스 스킬 정리
  - 주간 보스별 주요 공격기·방어기를 정리하고, P1 보스가 떠 있을 때 스킬이 안 맞던 문제 점검
- 초보자 상점
  - 누구나 쓸 수 있게 열고, 장비를 직업별 패키지로 묶어 판매, 기존 직업 아이콘 활용과 정렬 수정
- 튜토리얼 안내서 아이템
  - 인벤토리에 있는 것이 가장 직관적이라는 판단으로, 책 대신 소모품 형태 안내서와 더 흥미로운 대화창 구성
- NPC 대사 방식 개편
  - 대사 안에 목표와 숫자를 분명히 쓰고 가야 할 NPC를 색으로 강조하는 방식을 정해, 호감도 NPC 전체와 직업 숙련 장부 대사에 적용
- 특수 상점 재화 설명 수정
- 베어월드 지도 해금 표시
  - 권한에 따라 아직 못 가는 지역을 회색으로 덮고, 지형 범위에 딱 맞게 회색 영역을 다듬음
  - 조건에 따라 메뉴 제목도 바뀌게 하되 코드 변경 없이 설정으로 해결해 MR 제출, 이동 버튼 변경(노드 안 Shift+F는 유지)
- 코드 저장소 설정 원칙 정리
  - 여러 개발자가 함께 보는 코드에는 사용법을 보여 주는 예제 설정만 남기고 운영 설정은 올리지 않기로 정하고, 코드 가이드에 맞지 않는 문서를 걷어냄
- 잠재능력 결과 안내
  - 돌린 뒤 지금 얻은 능력치가 바로 보이도록 안내 추가
