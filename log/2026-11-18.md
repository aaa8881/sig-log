# 2026-11-18

## 베어타운

- 새 직업 UI 제작
  - 직업 메인, 클래스 선택, 선택 확인, 직업 상세, 초기화 확인 5개 화면을 목업부터 잡아 새로 제작하고 기존 직업 창을 대체
  - 직업 카드 원화의 자글자글한 선을 손으로 정리하고, 배경판과 하단 버튼을 기존 장부 판과 맞춤
  - 레벨과 경험치 배수를 숫자 글리프로 조합해 화면에 깔끔하게 표시, 직업 선택 창의 정보 표시와 정렬, 공예가 초상 크기 수정
  - 코드 리뷰를 거쳐 코드 가이드에 맞게 정리하고, 수정 의도를 담아 MR 제출
- 강화 콘텐츠 반영
  - 토르·큐피드·펭귄 강화와 전투 장비 T2에서 T3로의 전승 비용을 개발 서버에 넣고, 특정 강화석이 다른 강화에 영향을 주지 않도록 처리
- 희귀도 꼬리표 교체
  - 희귀도 꼬리표 이미지 5장을 새 시안으로 교체
- 리소스팩 글리프 로드 복구
  - 리소스팩의 유니코드 글리프가 통째로 적용되지 않던 문제를 클라이언트 로그로 찾아 복구
- 직업 시스템 보강
  - 새 직업 창에 직업 랭킹 버튼과 준비 중 칸을 넣고, 전투·생활·제작 카테고리별 선택 권한과 권한 없음 안내를 정리
  - 직업 스킬 메뉴 정렬과 전체 보기 버튼을 손보고 스킬 강화 화면 누락분 점검
- 낚싯대 강화석 데이터 유지
  - 강화 후 낚시 강화석 데이터와 로어가 사라지지 않게 고치고, 다른 강화에는 영향이 없도록 확인해 MR 제출
- 옵션 화면 한국어 표시
  - 켜짐·꺼짐을 활성화됨·비활성화됨으로, 변경 안내도 한국어 문장으로 바꿈
- UI 점수 평가 완료
  - 전체 UI를 점수로 평가하는 작업을 마무리
- 전투 콘텐츠 경제 정리
  - 베어월드 전투 콘텐츠에서 나오는 재화와 보상의 경제 조정을 정리하고 콘텐츠 확정
- 가공 기계 알림 아이콘
  - 영웅 꼬리표가 붙어 있던 기계 알림을 기존 시스템 안내용 곰 아이콘으로 통일
- 보스 보상 상자 웨이브 제작
  - 레이드 마지막에 유저보다 훨씬 큰 보상 상자가 나와 10번 때려 여는 웨이브를 새로 만들고, 남은 타격 수 표시와 열림 애니메이션 추가
  - 토벌 참가자인데 상자가 안 열리던 버그와 상자가 늦게 나오던 문제 수정
- 연출 보강
  - 직업 레벨업은 베리 팝업으로, 던전 결과는 등급별 팝업(S등급은 베리)으로 바꾸고, 제작 완료 알림 개선
  - 잠재능력을 돌린 뒤 얻은 능력치가 바로 보이도록 결과 안내 추가
- 바람 균열 드롭 점검
  - 바람 결정체가 특정 몹에서만 나오는지 확인, 전설 등급이라 낮은 단계에서 안 나오는 공식이 맞음을 확인
- 작업 이관 정리
  - 다른 에이전트가 이어받을 수 있게 이관 체크리스트를 마무리하고 시작점 문서와 기억 사본 정리
  - 직업·레이드·공용 코어·드롭 작업을 MR로 올리고 리뷰어 지정
