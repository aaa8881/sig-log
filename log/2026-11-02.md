# 2026-11-02

## 베어타운

- 전투 경험 전면 개편 착수
  - 던전 서버와 베어월드에서 탐험 경험이 따로 노는 문제를 풀기 위해 두 곳을 합치고, 몬스터와 보스를 새로 짜기로 결정
  - 전투력(power_value)을 현존 장비·강화·룬 기준으로 분석하고, 장비를 바꾸지 않고 PvP와 PvE를 함께 다룰 새 전투력 공식을 시뮬레이션
  - 이후 상위 장비를 낼 때 어떻게 확장할 수 있는지도 검토
- 운영 문의 자동화 봇 새로 제작
  - 기존 베어봇을 대신할 봇을 마크 운영 서버가 아닌 별도 서버에서 돌리도록 설계, 나중에 서버를 옮길 수 있게 구성
  - 단계 0 코드 작성과 로컬 확인
- 위키 시세·랭킹 데이터 수집기 재검토와 운영 설치
  - 예전 설치기가 커널 업데이트를 일으켜 SSH가 끊긴 일을 계기로, OS 패키지를 건드리지 않는 설치기로 다시 만들고 설치 전후 패키지가 같은지 검증
  - 운영 서버 설치와 첫 수집 성공, 웹 저장소에 커밋
  - 도메인 네임서버 이전은 다음 긴 점검 때 하기로 하고 이어서 할 순서를 문서화
- 서버별 퀘스트 구조 검토
  - 서버마다 퀘스트를 나눠도 유저 진행도가 유지되는지, 야생 1·2·3처럼 같은 퀘스트를 여러 서버에 둘 때 진행도가 이어지는지 코드로 확인
- 베어타운역 대형 글씨
  - 스폰 역의 "베어타운역" 큰 글씨를 궁서체로 다시 쓰고, 테두리를 빼서 글자와 그림자만 남김
