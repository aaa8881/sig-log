## 베어타운

- 메뉴 로드 오류와 스폰 NPC 공통 문제 수정
  - 도움말 메뉴 설정 로드 에러 원인을 찾아 고치고, 한 NPC만이 아니라 스폰 NPC 전체에 있던 같은 문제를 함께 수정
- NPC 대화 작성 기준 정리
  - 대화 작성 기준을 스킬로 정리하고 매뉴얼을 빠르게 쓸 수 있게 다듬음, 플레이어는 존댓말을 쓰고 안 쓰는 항목은 삭제, 잘못 걸린 문구 변경 금지 해제
- 노드 사냥터 구성
  - 노드마다 몬스터 스포너와 중앙 필드보스 공간이 있는 사냥터를 하나씩 붙이는 구조로, 텔레포트로 연결
  - P3 사냥터는 거대 용 화석 머리가 보이게 배치하고 기존 선인장·장식 에셋을 걷어 절벽에 소품을 흩고, 사막 느낌 바닥을 정리
- 심사장 이탈 복귀 성능 점검
  - 심사장 밖으로 나가면 2초마다 되돌리는 기능이 전체 인원을 도는지 확인해 성능 문제를 검토
- 스폰 메뉴를 기본 메뉴로
  - Shift+F에서 스폰 메뉴가 바로 열리고 뒤로 가면 일반 메인 메뉴가 열리도록 구성, 베리와 함께하는 특급 뉴비 가이드를 대화창으로 연결
  - 옛 메인 메뉴의 이동 버튼 레벨 제한 등 업적 조건을 모두 삭제
- 납품 콘텐츠 조정
  - 너무 어렵다는 평이 많던 납품을, 주간 납품을 하는 실제 이유에 맞춰 조정하는 방향 정리
- 공용 코어 MR 검토
  - 다른 개발자가 올린 공용 코어 MR을 검토하고 필요한 부분 조정
- 스폰 메뉴 정렬·아이콘 보완
  - 빠진 설명·빠른 이동 아이콘을 채우고 가로 정렬을 맞춘 뒤, 매번 틀리던 가로 정렬 검사를 검수 절차에 추가
- 요새 이야기 1장 플레이 검증
  - 서버에 막 들어온 신규 유저 입장으로 1장을 직접 진행하며 막히는 곳을 고침
  - 아지매 대사에 /직업으로 직업을 고르는 안내 추가, 같은 선택지가 두 번 뜨던 버그와 직업 키트 지급 정리
  - 옛 메뉴 대신 Shift+F와 /길라잡이 안내로 바꾸고, 퀘스트 완료마다 베리 팝업·완료 문구·효과음 추가
  - 초반에 어울리지 않던 베리 심부름 조건 제거, 역의 베리에게 돌아가는 단계에서 막히던 문제 수정
