# 2026-10-22

## 베어타운

- AI 질문 답변 시스템 구축 시작
  - 패치노트, 위키, AI가 같은 공개 지식 원본을 쓰는 전체 구조 설계 (가벼운 판단 계층으로 비용 절감)
  - 위키 문서 기반 검색 시제품과 디스코드 봇 제작
  - 채널 공개 답변, 질문과 답변 함께 표시, 짧고 정확한 답변으로 조정, 대화 맥락 보관 기준 정리
  - 비용을 줄이기 위해 더 가벼운 모델로 전환 검토
- SigShop 호퍼 한도 상품 개선
  - 구매 시 안내 메시지와 현재 한도 표시 추가
  - 상점 설명에서 placeholder가 그대로 보이던 문제 수정 중
- AI 질문 답변 봇 개선
  - 답변 비용을 줄이려고 더 가벼운 모델로 전환
  - 엉뚱한 답이 나오던 원인이 답변 처리 구조에 있다는 걸 찾아 수정
  - 위키에 없는 일반 마인크래프트 질문도 답하도록 개선, 검색용 데이터 갱신
- 질문 답변·스승과 제자 시스템 기획
  - /질문 하나로 AI 답변을 먼저 받고, 부족하면 유저에게 물어보는 흐름 설계
  - 질문을 베어타운 전체 하나로 저장해 어느 서버에서든 같은 질문을 보고 답할 수 있게 구성
  - 질문자가 직접 채택한 답변에만 보상, 기한이 지나면 내공 반환
  - 스승과 제자가 단순 추천인 제도가 아니라 실제 관계로 이어지도록 기획 고도화
- ModelEngine 모델만으로 시네마틱 연출 실험
  - 별도 플러그인 없이 모델과 몹 설정만으로 탑승형 연출이 가능한지 검증하는 것이 목적
  - 열기구, 팝업 스토리북으로 가능성을 확인하고, 끊김과 방향 문제를 해결하며 제작 노하우 정리
  - 활용할 만한 연출을 여러 종류 시제품으로 제작, 인게임 확인 단계
- 대화창 기능을 SigLib으로 옮긴 뒤 환영·서버 안내 대화창 재등록
