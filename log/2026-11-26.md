# 2026-11-26

## 베어타운

- 아이템 그룹 기능
  - "이 중 아무거나 N개" 같은 재료 조건을 영혼석만이 아니라 어디서나 쓰도록 아이템 플러그인에 그룹 기능을 추가, 그룹은 아이템 데이터가 아닌 외부 설정으로 관리
  - 그룹은 아이템을 가져갈 때만 쓰이게 하고, 제작·드롭·강화에서 그룹 판별 규칙을 하나로 통일, 돌려줄 때 처리 방식 정리
  - 필요가 생긴 배경과 위험 지점을 리뷰어가 보기 쉽게 적어 MR 제출, 제작 쪽 MR은 하나로 합침
- 기력 기반 획득 전환
  - 제작에서 기력 소모를 빼고, 베어월드 드롭에서 기력을 쓰도록 공용 비용 기능으로 구현, 기존 드롭 횟수 제한은 삭제 예정
  - 기력 부족으로 전리품이 안 나오면 바로 안내하고, 기력 차감 저장은 묶어서 처리하도록 구성
- 제작 대기열 개선
  - 완료된 작업을 누르면 결과가 바로 인벤토리로 들어오게 하고, 시작 연출은 소리로만, 제작 시간 표시를 더 눈에 띄게 다듬음
  - 매초 화면을 다시 만들던 남은 시간 갱신이 무거운 것을 수치로 확인해 빼고, 완료 아이템이 늦게 사라지던 문제 점검
- 제작 체계 개편
  - 기본재·교역품의 대성공·영감 결과를 없애고 기본 성공과 추가 제작만 남기며, 숙련 경험치는 10레벨 기준 시간에 맞춰 다시 배분
  - 기본재 4등급 순서와 제작 시간(10초·1분·15분·1시간), 전투 장비 제작 시간과 연성서 양, 주간보스 재료 제외 등 조정
  - 원소 제작대 이름을 바로잡고, 주괴는 순수 원소 가루·조각·정수와 거푸집으로 만들게 변경, 결과 이름이 두 번 찍히던 로어 수정
  - 공예품에 원소 색과 아이콘을 붙여 한눈에 보이게, 대장장이 스킬 경험치를 제작 로어에 표시, 쓰지 않는 레시피 삭제
- 직업 밸런스
  - 직업별 획득량을 비슷한 시간에 맞추도록 나무꾼은 너프, 농부·어부는 버프, 장부 목표 30회로 조정
  - 교역가·위대한 창작가 스킬도 교본으로 올릴 수 있게 풀고, 장부가 다른 직업 스킬 레벨을 읽던 문제를 고쳐 MR 제출
  - 뉴비 지역 원소 가루가 직업마다 다르게 나오던 것을 똑같이 맞춤
- 원소강화·프레스티지 재료 조정
  - 원소별 수급량 자체를 맞추는 것을 목표로, 반지 기계 3일, 프레스티지 업그레이드는 주간보스 결정석과 노드 대표 재료로 정리
- 균열 보상 점검
  - 균열 웨이브별 몹과 S·A 랭크, 완료 보상 설정을 모아 확인
- 제작창·상점·퀘스트 GUI
  - 제작대 3장과 고친 4장 설치, 쓰지 않을 이동 아이콘 삭제, 스승 질문 화면 조정
  - AI 티가 남은 퀘스트·출석·시즌패스 화면을 독립 검수 후 다시 손봄
- 복귀 유저 판정과 질문 봇 점검
  - 복귀 유저가 신규로 잡히던 문제를 검토하고 코드 개선점을 찾음, 위키·스승 질문 시스템과 질문 관리 봇 운영 매뉴얼 작성
